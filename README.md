# 贾诩方案 · Jia Xu Plan

> 主公，谋事先审其势，临机当辨进退。臣愿陈其利害，献可行之策。

一个以贾诩史料为启发的 Agent Skill：分析复杂决策、谈判与组织协作，用文言谋士口吻献策，称用户为“主公”，自称“臣”，必要时在末尾附白话译文。

## 它如何分析

**定目标与底线 → 审势 → 判断各方利益 → 择时 → 比较方案 → 落实行动。**

- 看实际决策权、资源依赖与时间压力，区分事实、推断和未知。
- 判断合作方的需求、顾虑与兑现能力，寻找能持续的利益安排。
- 同时计算行动风险和等待成本，随关键条件变化调整方案。
- 给出具体行动、沟通话术、进退条件，以及足以推翻当前推荐的证据。

文言风格贯穿开场、进度说明与最终献策；代码、数字、日期、专业术语，以及准备直接发送的现代业务材料仍保持准确。用户可以要求纯文言、完整白话翻译或另换称谓。

## 安装

将本仓库完整放入个人技能目录，文件夹命名为 `jia-xu-plan`。Codex 默认位置为 `~/.codex/skills/jia-xu-plan`；如已配置 `CODEX_HOME`，则使用该目录下的 `skills/jia-xu-plan`。

例如，在默认配置且目标文件夹尚不存在时：

```bash
git clone https://github.com/zhaoshen9299/jia-xu-plan.git ~/.codex/skills/jia-xu-plan
```

保留 `SKILL.md`、`agents/` 和 `references/` 的相对位置。其他支持 `SKILL.md` 的 Agent 可按其自身规则加载。

## 调用示例

```text
用 $jia-xu-plan 分析：两个部门都支持项目，却都不愿投入人力。
周五要确定排期，请给我主方案、沟通话术和后手。
```

```text
用贾诩方案分析以下合作选择。纯文言，称我为主公；
请说明何时宜进、何时宜退，以及什么证据会推翻你的建议。
```

文风示意：

> 主公，今所当争者，非再得一句“支持”，乃使人力之数、调度之权、交付之责，皆有所属。宜先定承诺，后定排期。

查看 [完整文言献策示例与译文](references/voice-example.md)。示例为自拟文辞，并非贾诩原话。

## 史料与边界

主要参考《三国志》卷十贾诩本传及裴松之注。史料叙事、注家评论与现代提炼分开说明；保留对李傕攻长安、缓攻荆州等问题的批评与分歧。

“贾诩方案”是现代整理的决策框架，不能复原历史人物的真实内心。历史类比用于提出可验证的问题，建议仍取决于现实证据、用户目标和权限。技能不把猜测当事实，也不将离间、欺诈或伤害他人转成行动指引。
